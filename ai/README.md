# AI

Documentation and configuration for AI-assisted development tools.

The purpose of this directory is to document installation, configuration, authentication, workflows, and lessons learned for each AI platform.

## Supported Tools

### Claude Code

Repository-aware development assistant focused on implementation, refactoring, and architecture work.

### Codex CLI

OpenAI development assistant used for code generation, repository operations, and automation.

### Gemini CLI

Google AI development assistant used for large-context analysis, documentation review, and software development tasks.

## Objectives

* Maintain consistent configuration across machines
* Document authentication procedures
* Track installation requirements
* Capture workflow patterns and best practices
* Reduce setup time during workstation rebuilds

## Future Additions

* Prompt libraries
* MCP configuration
* Agent comparison notes
* Workflow benchmarks
* Tool-specific bootstrap procedures

## Philosophy

AI tools are treated as first-class development dependencies and should be documented with the same rigor as operating systems, programming languages, and package managers.
